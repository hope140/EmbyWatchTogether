# Watch Together v1.7.0.1 测试版

## 修复与改进

- 修复部分 Emby Web 版本打开或离开一起看页面时停留在“正在加载”、影响后续页面跳转的问题。
- 修复“房间 / 创建与邀请 / 设置”标签在真实宿主中可能跳转到错误地址的问题。
- 修正旧版桌面客户端的下拉箭头位置，保持与控件垂直居中，标签换行时也能正确定位。
- 参与者、主用户和更新通道沿用 Emby 原生普通单选方式；刷新房间或编辑名称时保留未变化的下拉选项与有效选择。

## 配置与升级

- 房间、配置和持久化格式保持兼容，无需迁移；同步引擎、服务端权限与签名更新信任规则保持原有行为。
- 安装后按 Emby 提示重启服务器。网页可完整刷新后重新进入一起看，桌面客户端可完全退出后重新打开。
- 本版用于 beta 测试通道；stable 通道继续使用 v1.6.1.0。

## 验证范围

- 已完成浏览器 89 项与 .NET 545 项回归，真实 Web 分页和离页检查通过；用户确认了最终普通单选外观方案。
- 客户端此前“三个下拉框同时无法打开、重启后恢复”的原始过程尚未复现；本版不能据此声称已确认其全部触发原因。
- 创建与接受邀请、加入/暂离/结束房间、双端播放控制和换集，仍需真实使用反馈。
