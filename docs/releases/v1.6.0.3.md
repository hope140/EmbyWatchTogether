# Watch Together v1.6.0.3

## 发布修正

- 修正 beta 更新检查在遍历 GitHub 历史 Release 时的选择顺序。旧逻辑可能先遇到缺少固定资产的历史版本，并误报“测试版发布缺少固定资产”。
- 更新检查现在先选择最高规范的非 draft stable 或 prerelease 版本，再验证该版本的 DLL、manifest 和 detached signature 固定资产。
- 如果最高版本自身缺少固定资产，更新仍会拒绝；签名校验、受信任来源、程序集身份和版本校验保持不变。

## 版本与兼容性

- `v1.6.0.2` 的发布资产本身齐全且不可变；`v1.6.0.3` 是针对 beta 更新检查的修正版本。
- 本版本不改变房间持久化格式、同步协议、配置语义或签名信任根，也不新增配置项。
- 本版本为 beta/prerelease，稳定版 `1.5.0.0` 不变。本文只记录发布流程修正，不能替代本修正的真实 Emby UI 验收。

## 升级注意

- 管理员选择 beta 通道后，更新任务会按最高规范版本检查并验证固定签名资产；历史低版本资产缺失不会阻断当前最高版本，当前最高版本缺少资产仍会安全失败。
- 如需回滚，停止 Emby 后恢复升级前备份的 DLL；不修改已有 `v1.6.0.2` tag 或 Release。
