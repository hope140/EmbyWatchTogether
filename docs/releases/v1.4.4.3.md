# Watch Together v1.4.4.3

## 版本性质

- 本版本从 `beta` 分支发布为 GitHub prerelease，兼容基线为正式版 `v1.4.4.0`。
- 本包包含 S1—S4 的回归保障、房间诊断、诊断页面、参与者重新同步和非管理员入口修复。
- 这是测试版，不代表真实双端播放已经完成验收。

## 修复与改进

- 插件页同时启用 Emby 的用户菜单入口，非管理员可以从用户菜单打开 Watch Together 页面。
- 页面继续按服务端权限隐藏创建、配置和管理员控制，非管理员只读取自己参与的房间并使用参与者操作。
- 管理员入口和现有房间、同步状态机、诊断及重新同步接口保持兼容。

## 升级与测试注意

- 安装完成后需要重启 Emby 才能加载新版本。
- 自动测试和构建已通过；需要在非管理员账号下确认用户菜单入口、房间显示和“请求重新同步”实际可用。
- 如需回退，使用 Emby 插件管理或保留的上一版签名资产，不要手工修改已发布 tag。
