# Watch Together 路线图

本页只记录能力方向和延期决策。当前版本、交付与待确认事项见[当前排期](development-roadmap.md)，逐版变化见[发布日志](releases/README.md)。

## 已整合能力

- 双人同步观看、房间生命周期和一次性邀请。
- Media Handoff：参与者打开主用户目标 Item 后进入 Barrier；晚到换集、停止恢复和暂停等待受现有身份与时限约束。
- Phase E：参与者原会话短暂缺失时的有限恢复，以及持续明显漂移的低频保守对齐。
- Emby 原生三页界面、媒体与成员展示、诊断与脱敏导出、签名更新和通道设置；普通用户保留自己的房间与邀请。

## 后续方向

管理员页面延后至当前测试线转正式版之后，届时另行确认范围。此安排不构成实现、正式发布或部署授权。

## 长期边界与延期

当前路线不包含设备迁移、Session migration、Primary transfer、连续追帧式 Seek 或跨服务器同步。2026-10-19 决定无限期延期的 strict-follow 与多人同步观看保持原状；恢复需另行确认。历史整合与验收证据见[历史索引](history/README.md)。
