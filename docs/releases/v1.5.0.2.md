# Watch Together v1.5.0.2

## 版本性质

- 本版本从 `beta` 分支发布为 GitHub prerelease，基于稳定版 `v1.5.0.0`。
- 本版本用于验证 Watch Together 菜单入口修复。

## 修复内容

- Watch Together 页面统一通过 Emby 用户菜单提供，管理员只会看到一个入口。
- 普通用户继续通过用户菜单打开现有 `WatchTogetherDiagnostics` 页面。
- 页面内部管理员权限判断、`setAdminVisibility` 以及房间和同步功能保持原有行为。

## 配置与兼容性

- 不新增配置项，现有插件配置和房间数据可以继续使用。
- 房间、邀请、同步、诊断和更新逻辑保持不变。

## 测试状态

- 完整 .NET 测试和 Release 构建通过。
- beta 版本仍需在真实 Emby 客户端确认管理员与普通用户的菜单显示。
