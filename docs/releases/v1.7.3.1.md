# Watch Together v1.7.3.1 测试版

本测试版提供简体中文、繁体中文和英文界面，并按账号记录播放通知语言。

## 变化

- 页面跟随可用的 Emby 界面语言；无法读取时依次尝试页面文化、页面语言和浏览器语言。繁体中文支持 `zh-Hant`、台湾、香港和澳门语言区域；其他未支持语言显示英文。
- 播放通知使用账号上次成功打开本页面时保存的语言，多设备以服务器最后收到的保存为准；从未保存时默认为简体中文。管理员自定义消息保留原文，插件更新的管理员广播仍为中文。
- 留空名称的新房间按创建页面语言生成默认名；邀请码建房使用接受邀请页面的语言。名称创建后保持不变，旧房间不迁移，自定义名称保留原样。
- 移除页面中的通知语言说明行，规则保留在 README；页面和控制器缓存键更新至 V30。

## 验证与安装

- 用户已验收界面语言切换和房间名称；播放通知尚未进行真实客户端验收。自动测试和模拟宿主不能代替实际播放验收。
- 此前本地未签名的 `1.7.3.1` 预览是不同构建，不能仅凭版本号将其视为本测试版；若已安装该预览，自动更新不会因相同版本替换它。已手动安装 `1.7.3.2` 预览的服务器版本更高，也不会自动降级到本版。
- 手动安装前请备份当前插件 DLL，停止 Emby Server 后替换，并重新启动 Emby；需要回滚时可恢复备份。安装后重新打开插件页面，继续观察实际客户端与播放通知行为。
