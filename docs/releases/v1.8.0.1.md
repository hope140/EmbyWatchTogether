# Watch Together v1.8.0.1 测试版

## 本次更新

- 邀请码经服务器确认已失效后，邀请页会收起旧邀请码和复制按钮。若账号已有房间，可从邀请页直接前往房间。邀请码列表读取失败时，页面会显示读取失败提示。
- 我的房间会根据当前状态显示换片、对齐、等待重连或需要重新同步，并在需要重新同步时突出已有操作。同步恢复后会更新状态。
- 客户端暂时未上报播放位置时，插件会等待有效位置，避免错误跳到开头或提前判定进度已经对齐。实际播放位置为 0 秒时仍可同步。

## 安装

首次安装请选择 [v1.8.0.0 正式版](https://github.com/hope140/EmbyWatchTogether/releases/tag/v1.8.0.0)。如需体验本测试版，可沿用现有配置和房间数据。安装或更新后重启 Emby Server，再打开插件页面。
