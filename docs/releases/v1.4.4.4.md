# Watch Together v1.4.4.4

## 版本性质

- 本版本从 `beta` 分支发布为 GitHub prerelease，兼容基线为正式版 `v1.4.4.0`。
- 本包包含 S1—S4 能力，以及非管理员 Watch Together 页面布局和文案优化。
- 这是测试版，不代表真实双端播放已经完成验收。

## 界面改进

- 非管理员页面将房间区标题显示为“我的房间”，不再显示管理员流程编号。
- 非管理员空状态和使用说明改为参与者视角，提示加入房间和请求重新同步。
- 管理员页面继续保留“2. 房间”和创建房间流程。

## 升级与测试注意

- 安装完成后需要重启 Emby 才能加载新版本。
- 自动测试和构建已通过；请用非管理员账号刷新页面，确认标题、空状态和参与者说明显示正常。
- 如需回退，使用 Emby 插件管理或保留的上一版签名资产，不要手工修改已发布 tag。
