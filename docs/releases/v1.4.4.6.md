# Watch Together v1.4.4.6

## 版本性质

- 本版本从 `beta` 分支发布为 GitHub prerelease，兼容基线为正式版 `v1.4.4.0`。
- 服务端诊断事件环保留最近 500 条，页面和导出显示最近 50 条。
- 这是测试版，不代表真实双端播放已经完成验收。

## 诊断展示改进

- 前端按最新事件在前的顺序展示，最新记录出现在列表顶部。
- 导出 JSON 使用与页面一致的最近 50 条事件窗口。
- 服务端仍按时间顺序保留有界事件，超过 500 条时淘汰最早记录。

## 升级与测试注意

- 安装完成后需要重启 Emby 才能加载新版本。
- 请打开诊断详情，产生超过 50 条事件后确认页面和导出只显示最近 50 条，且顺序为最新在前。
- 如需回退，使用 Emby 插件管理或保留的上一版签名资产，不要手工修改已发布 tag。
