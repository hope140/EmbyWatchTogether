# Watch Together v1.8.0.3 测试版

## 本次更新

- 初次对齐等待有效播放位置时，如果主用户手动暂停，位置恢复后会保留暂停状态。等待期间手动继续播放也会生效。
- 换片后观察两端自然恢复时，短暂漏报位置会继续等待有效上报。原有换片期限和实际失步判断仍然生效。
- 修复俄语界面在窄屏上「继续播放」按钮文字溢出的问题。

## 安装

首次安装请选择 [v1.8.0.0 正式版](https://github.com/hope140/EmbyWatchTogether/releases/tag/v1.8.0.0)。从 v1.8.0.2 升级可沿用现有配置和房间数据。替换插件 DLL 后，重启 Emby Server 并重新打开插件页面。

[安装说明（中文）](https://github.com/hope140/EmbyWatchTogether/blob/v1.8.0.3/README.md#%E5%AE%89%E8%A3%85) / [Install (English)](https://github.com/hope140/EmbyWatchTogether/blob/v1.8.0.3/README.en.md#install)

播放回放和窄屏布局已有自动化用例覆盖。真实 Emby 双客户端专项验证仍待完成。
