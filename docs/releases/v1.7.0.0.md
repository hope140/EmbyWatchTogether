# Watch Together v1.7.0.0 测试版

## 新增与改进

- 页面分为“房间”“创建与邀请”“设置”，使用 Emby 原生标签与控件；普通用户可访问房间与邀请，管理员另有创建房间和设置。
- 房间采用视频展示区与控制区的双列布局，窄屏自动改为单列，整体增加浅色细边框。
- 同步观看时展示当前视频背景、片名，以及剧集的季数和集数；等待时显示对应原因和操作提示，媒体信息不可用时保留可用控制。
- 成员姓名旁显示 Emby 用户头像，缺失或加载失败时回退为姓名首字。
- 创建与邀请、设置页面按操作分组排列，保留原有房间、邀请、更新通道、Token 和诊断功能。
- 修正请求处理中切页再返回后创建/接受按钮可能持续禁用的问题，并防止旧诊断面板的迟到事件影响新页面。

## 配置与升级

- 房间、插件配置及已有持久化格式保持兼容，无需迁移；同步引擎与服务端权限逻辑保持原有行为。
- 安装后按 Emby 提示重启服务器。页面更新未生效时，可完整刷新页面后重新进入 Watch Together。
- 本版为 Pre-release，选择 beta 更新通道后可由既有更新任务检查；stable 通道继续使用 v1.6.1.0。

## 测试重点

- 请验证创建与接受邀请、加入/暂离/结束房间、双端暂停/继续/重新同步，以及主用户换集后的实际表现。
- 请验证设置保存、诊断查看与导出，以及不同客户端、主题和窗口宽度下的页面表现。
- 桌面客户端内容宽度可能受其宿主样式影响，该差异仍在客户端侧排查。
- 自动化回归与已有实机显示检查不能替代完整的真实双端功能验收；本版用于收集这部分反馈。
