## 自动验证与仍需实际观察的场景

- 角色失败/缺失/身份不匹配、账号/服务器/离页迟到结果、管理员真实 500、所属房间隔离和 V21 资源契约有自动测试覆盖。
- 配置保存前读取失败、提交结果不确定、提交后回读失败，以及结束/删除失败、暂离暂停失败等由自动测试覆盖；未在真实服务器人工注入全部故障。
- fixture 不能代替真实宿主或双端播放。已检查的 ETE 0.4.21 提示不显示标题、不按 timeoutMs 控制时长且串行展示；EWT 不修改该客户端行为。发送成功不等于用户已看到。

## 播放观察清单

以下是后续复核入口，不表示用户已经通过的 1.7.2.13 验收被撤销：

1. 正常换集的加载等待、双方起播和恢复跟随。
2. 原本暂停或等待中手动继续后的意图保留，以及自然对齐恢复条件。
3. 漂移、再次暂停、身份/媒体/权限变化、断连及超时后不复活旧控制命令。
4. 提示过期、通知开关与真实客户端显示顺序。

逐条历史条件见[1.7.2.13 验收原文](history/client-evidence-through-v1.7.2.18.md#v17213-待验收场景)。EWT 不提前切集、不依赖 ETE 专用 EOF 协议，也不修复 ETE 异常 EOF；未上报操作、同值暂停和容差内小幅 seek 不能可靠辨认。

## 如何补充证据

记录操作时间及其时区、服务器/双方客户端版本、插件版本与源码或 DLL 哈希、操作步骤、预期和实际结果。优先附插件导出的脱敏诊断及截图，不上传 Token 或完整未脱敏日志。普通地址栏请求缺少页面认证头时的 401，不能替代已登录页面验收。连续观看的口述观察可保留，但缺少具体构建、媒体与时段时不扩展为全场景通过。
