# Watch Together v1.4.4.5

## 版本性质

- 本版本从 `beta` 分支发布为 GitHub prerelease，兼容基线为正式版 `v1.4.4.0`。
- 本包包含 S1—S4 能力，并修复诊断详情在房间轮询后消失的问题。
- 这是测试版，不代表真实双端播放已经完成验收。

## 修复与改进

- 诊断详情在 5 秒房间状态轮询后保留，不再自动折叠或清空。
- 已读取的诊断结果和用户手动展开/收起状态会在卡片重建后恢复。
- 诊断请求在页面轮询期间完成时，结果会写入当前面板，不会因旧 DOM 节点被替换而丢失。
- 房间消失后会清理对应诊断缓存，避免残留旧房间信息。

## 升级与测试注意

- 安装完成后需要重启 Emby 才能加载新版本。
- 自动测试和构建已通过；请打开诊断详情并等待超过 5 秒，确认内容仍保持展开和可见。
- 如需回退，使用 Emby 插件管理或保留的上一版签名资产，不要手工修改已发布 tag。
