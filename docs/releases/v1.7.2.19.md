# Watch Together v1.7.2.19 测试版

房间名称可留空，创建时自动生成随机四位数字名，并完善邀请页面反馈。

## 本次变化

- 管理员手动创建和接受邀请创建房间均支持空名称；填写名称时沿用原行为。两处输入框提示为“留空自动生成房间名”。
- 创建时从未占用的“房间 #0000”至“房间 #9999”中随机选择一个，锁内检查、持久化并注册，避免并发重名。编号耗尽时明确失败，不占用成员或消耗邀请码；可改填名称。
- 已有房间保持原名称，不重新随机或迁移。编号只用于显示，不是安全凭证。
- 空名称邀请在接受前显示“接受邀请后生成房间名”，接受成功创建房间时才分配编号。
- 自动复制失败提示“自动复制失败，请手动复制邀请码。”，保留邀请码、有效期及创建成功结果，不重复请求。
- 三个页面、控制器及路由引用统一升级为 V23，避免复用旧脚本。请从插件菜单重新进入。

## 验证与升级

- 用户已确认对应 name-preview3 服务器预览。本地和 PR 回归覆盖 972 .NET、177 UI，包括随机索引、已有编号冲突、混合并发、10,000 编号耗尽与邀请重试、持久化、真实服务入口及剪贴板失败。
- 自动测试不等于真实服务器故障注入或全客户端验收；未人工注入所有异常场景。
- 本包产品行为与已验收预览一致，版本、源码及签名身份不同；不修改同步引擎、播放、服务端权限、邀请有效期或更新安装逻辑，不迁移配置和房间数据。
- beta/prerelease，正式通道不变。安装需要重启 Emby Server；先备份并确认不会中断活动播放。管理员页面仍延后至当前测试线转正式版之后。
