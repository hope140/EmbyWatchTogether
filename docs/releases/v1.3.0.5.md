# Watch Together v1.3.0.5（Beta）

## 本次变化

- 多会话选择更保守：运行时同分只沿用唯一历史 `SessionId` + `ItemId` 关联；没有历史或关联失效时保持等待。
- 手动暂停/继续增加冲突保护：Barrier 或任一参与者存在 Pending 时整次拒绝，不覆盖同步；成功操作不会误报陈旧 runtime error。
- 退出自动暂停返回稳定的 `Attempted`、`Succeeded`、`Failed` 汇总，管理页区分成功、失败和未尝试。
- 群发消息按目标隔离异常，单个目标失败仍继续后续目标，并返回 `Sent`、`Failed`、`Skipped`。

本版本不改变既有 API 字段、配置项或同步阈值；响应仅增加兼容字段。自动化测试不等于真实客户端验证。

## 部署与验证

本版本作为 Beta 手动部署观察，不创建 Tag 或正式 Release。请停止 Emby Server 后备份并替换插件 DLL，按 README 的人工安装步骤启动验证；本文不声称已部署或已完成真实客户端验收。

如需回滚，停止服务器并恢复此前备份的 DLL。Beta 期间请重点观察多会话等待、手动操作冲突提示、退出暂停汇总以及群发消息结果。
