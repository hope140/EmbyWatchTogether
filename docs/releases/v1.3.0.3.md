# Watch Together v1.3.0.3（Beta）

## 本次观察内容

- 运行时和管理会话选择会传入当前时间，使默认 60 秒过期的 Online 幽灵会话不能组成有效同步配对，降低旧会话误参与同步的风险。
- 当同一用户存在多个 Online 播放 Session 时，增加低噪声的 `multiple-session selection` 诊断。日志包含处置阶段和短标识，便于观察选择过程；诊断不改变会话选择或同步行为。
- 未修改配置、房间格式、公开 API 和正常单会话语义。

## 部署与验证边界

本版本先作为 beta 手动部署观察。当前真实环境中的偶发多会话场景尚未复现，因此仅记录观察日志关键字 `multiple-session selection`，不宣称已完成客户端验证。正式 Release 尚未创建。

升级或回滚前请按 README 中的人工安装步骤备份并替换插件 DLL；如需回滚，恢复此前版本的 DLL。
