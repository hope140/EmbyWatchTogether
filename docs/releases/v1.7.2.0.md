# Watch Together v1.7.2.0 测试候选

## 修复与改进

- 远程播放、换片和消息发送增加独立的有界等待。底层任务不响应取消或在调用入口阻塞时，轮询可按期限返回并继续处理其他房间。
- 同一会话的未完成传输共用一个槽位，迟到完成仅释放资源；正常已完成命令不会因清理回调尚未运行而挡住下一条命令。
- 确认一方停止播放时，终止旧 Pending 序列，再执行另一端的暂停，保留既有停止观察窗口和晚到换集行为。
- 换片 Handoff 期间，手动暂停与继续按同步冲突处理，保持当前换片流程和待确认状态。
- 状态原因使用本次读取的错误快照，避免刷新房间时因错误被并发清空而抛出空引用异常。
- beta 更新候选选择跳过历史非规范标签，继续严格验证最高规范版本的固定资产与签名。
- 普通设置保存保留内部待重启版本，更新安装通过同一配置锁记录已完成事实，防止旧设置覆盖后重复安装。

## 配置与测试

- 房间和插件配置格式保持兼容，无需迁移。
- 本包用于 NAS 实机测试。已进入底层的传输无法被强制撤回；未完成任务继续占用会话槽位，直到实际结束。
- 本地自动测试与服务器加载检查分别记录；真实双客户端的起播、暂停/继续、Seek、换集、停止和恢复由本轮实机测试确认。
- 本候选不代表已创建 GitHub Release 或完成公开签名发布。
