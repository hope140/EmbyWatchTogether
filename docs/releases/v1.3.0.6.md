# Watch Together v1.3.0.6（Beta）

## 本次变化

- 修正 `Watching` 开始后的停止观察：停止状态持续达到 2 秒才确认停止。
- 停止观察期间，临时同用户替换的会话不能清除观察；不同 `SessionId` 的替换（尤其是不可远控的快照）不会被当作恢复。
- 只有原 `Previous SessionId` + `ItemId` 且会话在线、未停止并支持远程控制时，才算恢复并清除停止观察。
- 修复生产序列中停止确认后另一方可能没有暂停或没有收到提示的问题；暂停和提示仍按各自配置开关执行。

本版本不改变既有 API 字段、配置项、首次触发条件或 2 秒阈值。自动化测试不等同于真实客户端验证。

## 部署与验证

本版本作为 Beta 手动部署观察，不创建 Tag 或正式 Release。请按 README 的人工安装步骤备份并替换插件 DLL，再手动观察停止、恢复、暂停和提示行为；本文不声称已部署或已完成真实客户端验收。

如需回滚，停止服务器并恢复此前备份的 DLL。Beta 期间请重点观察首次停止触发、2 秒边界、原会话恢复条件，以及另一方暂停和提示是否同时执行。
