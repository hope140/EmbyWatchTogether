# Watch Together v1.6.0.4

## 新增与改进

- 改进 beta 更新检查在较慢 GitHub/CDN 网络下的固定资产下载等待时间。
- DLL、manifest 和 signature 三项固定资产的下载超时调整为 60 秒；Releases API 查询仍使用 20 秒超时。

## 配置与兼容性

- 本版本不改变配置格式、更新通道、签名验证、哈希验证、来源和程序集身份校验。
- 下载失败时仍会清理临时文件并拒绝安装，签名校验失败仍会安全终止更新。

## 升级注意

- 已在一台实际 Emby 服务器上完成更新检查任务验证，较慢固定资产下载可以在超时范围内完成；这项验证只覆盖更新检查和资产校验，不代表新版已自动安装，也不代表所有客户端或网络环境都已兼容。
- 如果旧 DLL 的更新任务持续失败，可以人工安装可信的新版 DLL，并按 Emby 插件升级流程重启服务器。
