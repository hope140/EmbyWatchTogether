# Watch Together v1.7.2.14 测试版

修复关闭原生 JavaScript 对话框的宿主中，暂离、结束房间等操作没有反应的问题。

## 本次变化

- 暂离、结束/删除房间、管理员重新同步和清除 GitHub Token 改用 Emby 宿主通用确认框，默认选择取消。明确确认后才发送操作请求；取消或关闭不执行操作。
- 等待确认时防止重复弹窗，并在页面、账号、服务器、路由、权限或房间成员变化后丢弃过期操作。
- 确认模块无法加载时显示即时失败提示，不执行未经确认的操作。

## 验证与边界

- 自动化覆盖确认、取消、模块加载失败、重复操作与生命周期变化。测试夹具模拟宿主模块契约，不能替代真实 Emby Web、新 Windows 客户端和旧客户端的显示、焦点及返回键验收。
- 本次仅修改前端确认流程及测试、文档，不改变同步引擎、播放协议或 ETE EOF 行为。
- beta/prerelease，正式通道不变。配置和房间格式不迁移；安装需要重启 Emby Server。本发布说明不代表已经完成服务器安装或真实客户端验收。
