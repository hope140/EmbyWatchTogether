# Watch Together v1.7.1.0 正式版

## 新增与改进

- 将原生分页、房间媒体展示及相关兼容修正从 beta 测试线纳入正式版。
- 页面分为“房间”“创建与邀请”“设置”，沿用 Emby 原生标签与控件；普通用户可访问房间与邀请，管理员另有创建房间和设置。
- 同步观看时展示当前视频背景、片名、季集和成员头像；等待或媒体不可用时显示原因及操作提示，头像失败时回退为姓名首字。
- 房间使用媒体与控制双列布局，窄屏改为单列，保留原有房间、邀请、更新通道、Token 和诊断功能。
- 修正部分宿主中的页面加载、标签路由、原生下拉箭头及切页后按钮持续禁用问题；旧身份、旧媒体请求和迟到事件不得回写新页面。
- 增补浏览器回归，并在 Windows CI 执行锁定的 Playwright 测试。

## 配置与升级

- 从 v1.6.1.0 或 v1.7.0.x 升级无需迁移房间、插件配置或持久化数据；同步核心、服务端权限及签名信任根不变。
- 本版为新的 stable Release，使用独立的 v1.7.1.0 tag 和签名资产。原有 v1.7.0.0、v1.7.0.1 测试版及其资产保留。
- 安装后按 Emby 提示重启服务器；网页可完整刷新后重新进入一起看，桌面客户端可完全退出后重新打开。此 GitHub 发布不会自动执行服务器替换或重启。

## 验证与已知边界

- 用户报告已在测试版完成实际验收，未发现问题。该结论为用户反馈，不代表本次发布代理逐项操作了真实客户端，也不推断未提供的客户端版本。
- 已有 beta Linux 回归为 .NET 545 项、浏览器 89 项和四组 PowerShell 检查通过；此次正式版准备与合并提交的 CI 结果见对应 PR 和发布工作流。
- 此前客户端“三个下拉框同时无法打开、重启后恢复”的原始触发过程尚未复现，不能声称已确认全部触发原因；客户端和网络能力仍以实际环境为准。
