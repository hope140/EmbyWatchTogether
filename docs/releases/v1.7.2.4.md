# Watch Together v1.7.2.4 测试版

本版本修复重启前重复更新可能覆盖已安装较高版本的问题，并整理安装、使用与兼容性文档。包含 v1.7.2.3 的同步提示合并与过期快照保护。

## 修复与改进

- 已安装更新、等待重启时，后续检查以运行版本和待生效版本共同判断可升级范围，不再用相同或更低版本覆盖待生效文件。自动检查和手动安装均受保护；仍可安装比待生效版本更高的更新。
- 将三段版本末尾缺失的零与对应四段版本视为相同版本，避免重复安装。
- README 补充房间首页展示图，整理安装、页面入口、播放限制与排错说明。展示图经过 AI 示意处理，部分文字与实际界面不同，不作为真实功能截图或验收证据。

## 配置与兼容性

- 保持现有房间和配置格式，无需迁移；不改变签名验证、信任密钥或更新通道默认值。
- 房间仍为同一台 Emby Server 上的两名用户；双方需使用支持远控的客户端和 1 倍速播放。

## 升级注意

- 本版用于 beta/prerelease 通道；Latest 正式版保持 v1.7.1.0。
- 安装后按提示重启 Emby Server，待生效版本将在重启后加载。升级前可备份旧 DLL 以便回滚。
- 自动化回归不能替代真实服务器升级与双客户端播放验收；这些现场场景仍待实际使用反馈，不宣称已完成验收。
