# Watch Together v1.5.0.1

## 版本性质

- 本版本从 `beta` 分支发布为 GitHub prerelease，兼容基线为 stable `v1.4.5.0`。
- 本版本开始阶段 C 自助邀请与房间生命周期测试，尚未宣称稳定版或完成真实双客户端验收。

## 新增能力

- 普通用户可以创建 15 分钟有效的一次性邀请码，邀请码只保存校验值，不写入 `rooms.json`。
- 另一位已认证用户接受邀请码后，服务端原子创建双人自助房间并消费邀请码。
- 支持有效邀请查询、撤销、过期、重放保护、并发接受保护和接受尝试速率限制。
- 自助房间创建者可以结束自己的房间，管理员继续可以管理所有房间；原有退出后仍属于成员的语义保持不变。
- Watch Together 页面增加邀请码创建、复制、接受、撤销和稳定状态反馈，管理员旧式建房和同步控制保持不变。

## 兼容性与限制

- 现有 `rooms.json` 可继续读取；旧房间缺少新增字段时按管理员创建的旧式房间处理。
- Emby 重启后未接受的邀请码失效，需要重新创建；已经创建的房间不受影响。
- 本阶段仍只支持同一服务器的双人房间，不引入多人、跨服务器或任意换片。

## 测试状态

- 自动测试、Release 构建、发布静态检查和 Windows CI 已通过。
- NAS Basic4 部署后需完成页面创建/接受/撤销和双账号实际播放验收，再决定是否推进 `1.5.0.0` stable。
