# Watch Together v1.8.0.2 测试版

## 本次更新

- 新增日语、韩语、俄语、法语和德语界面。支持对应的地区设置，例如 `ja-JP`、`ko-KR`、`ru-RU`、`fr-CA` 和 `de-CH`。
- 固定播放通知使用接收账号保存的语言，自动生成的房间名使用建房或接受邀请时的页面语言。手动填写的名称和通知保留原文。
- 简体中文、繁体中文、英文与现有同步操作照旧。

## 安装

首次安装请选择 [v1.8.0.0 正式版](https://github.com/hope140/EmbyWatchTogether/releases/tag/v1.8.0.0)。升级到本测试版可沿用现有配置和房间数据。安装后重启 Emby Server。修改 Emby 界面语言后，重新打开插件页面即可应用。

[安装说明（中文）](https://github.com/hope140/EmbyWatchTogether/blob/v1.8.0.2/README.md#%E5%AE%89%E8%A3%85) / [Install (English)](https://github.com/hope140/EmbyWatchTogether/blob/v1.8.0.2/README.en.md#install)

界面、地区码和固定通知已通过自动化检查。译文未经母语审校。
