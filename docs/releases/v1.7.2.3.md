# Watch Together v1.7.2.3 测试版

本版本减少拖动播放进度时的连续提示，并补充确定过期快照的控制保护。保留 1.7.2.2 的同步加速、远控有界等待和 Waiting Pause 限额修复。

## 修复与改进

- 一次暂停、拖动、继续过程中，不再逐条显示暂停、调整进度和继续提示；正常对齐完成后双方各收到一条结果提示。
- 同一对齐周期的自动重试最多提示一次；排队提示绑定同步周期和阶段，新一轮对齐或阶段结束后丢弃过时提示。停止、不同视频等异常提示仍保留。
- 稳定观看时，双方身份和同步资格均有效且没有待确认命令时，忽略同一身份下时间明确倒退的快照，避免确定过期的暂停状态触发新的远控。新会话、换片、停止、资格丢失和待确认命令继续沿原流程处理。

## 范围与限制

- 这些结论来自合成回归，不代表已证明用户现场发生了旧状态回放。快照的 LastActivityDateUtc 不是播放事件序号，时间相同或更新的旧内容仍无法与真实新操作区分，因此保留真实暂停、继续和新 seek 的语义，不宣称全面解决客户端乱序。
- 同步资格、Pause → Seek → Restore 流程及原确认容差保持；未修改客户端产品。
- 本版为 prerelease 测试版，不替换 Latest 正式版。本轮不部署或重启 NAS；真实双端播放验收尚待执行。
