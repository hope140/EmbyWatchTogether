# Watch Together v1.3.0.2

## 修复

- 修正部分 Windows 客户端中的房间卡片颜色。页面背景色不再被错误地用于房间卡片，卡片与其他面板的颜色更加协调。
- 房间卡片改用客户端提供的 `--card-background-*` 主题变量，并保留 `hsla()` 的透明度能力；默认 `alpha` 为 `1`，在未提供完整主题变量时仍显示为不透明卡片，避免回退为页面蓝底。
- 未修改房间同步、按钮操作、服务端 API 或数据格式。

## 升级注意

1. 更新插件 DLL 后重启 Emby Server，使嵌入式管理页资源重新加载。
2. 重新打开 Watch Together 管理页；如仍看到旧颜色，退出并重新打开客户端，或清理页面缓存后再检查。
3. 重点确认“房间”卡片与页面主题协调，卡片正文、状态徽章和按钮文字仍清晰可读；网页端浅色主题应继续显示浅色不透明卡片。
