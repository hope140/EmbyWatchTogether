# Watch Together v1.3.0.0

## 新增与改进

- 播放端会收到约 3 秒的中文提示，覆盖暂停、继续、手动进度调整、重新同步、加入、退出、打开不同视频和同步完成。
- 管理页为每个房间提供独立的处理中、成功和错误反馈。成功提示约 8 秒后清除，错误会保留到下一次同房间操作；后台轮询不会覆盖操作结果。
- 管理页展示安全、可执行的中文状态原因，并明确重新同步可能暂时暂停播放；删除房间只移除同步关系，不删除媒体。

## 配置与兼容性

- 新增默认开启的 `NotifyOnSyncActions` 设置，可热更新，并与停止播放提示开关独立控制。
- 现有房间和配置保持兼容；消息提示发送失败不会影响同步状态。

## 升级注意

- 更新插件后请重启 Emby Server，使新版本加载生效。
