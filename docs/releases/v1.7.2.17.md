# Watch Together v1.7.2.17 测试版

精简操作确认与结果提示，让结束、删除和暂离的反馈更清楚。

## 本次变化

- 结束和删除确认缩短为“结束/删除‘房间名’？双方将退出房间。”；结束操作的进行中和失败提示使用“结束”，管理员删除使用“删除”。删除成功简化为“房间已删除”。
- 暂离确认保留可重新加入和尝试暂停对方；结果继续区分已确认暂停、暂停未确认、暂停失败，暂停失败警告仍持续显示。
- 缩短重复按钮说明、成员说明、接受邀请、加入、重新同步与清除 Token 提示。保留邀请码有效期、可能切换视频，以及请求已受理不等于执行成功等必要信息。
- 确认框行为、toast 备用提示、配置保存结果不确定的提示保持不变；没有布局、同步引擎、权限、更新安装或其他业务变更。

## 验证与边界

- 用户已确认操作文案预览；自动测试覆盖结束/删除的确认、进行中、失败用词及暂离三个结果，包含失败警告持续可见。
- 真实故障分支未人工注入验收。自动测试和文案预览确认不等于所有客户端、屏幕阅读器或双端播放场景的全量验收。
- 页面资源与已确认的 1.7.2.16+actions-preview.20261112 预览一致；公开包具有 1.7.2.17 程序集版本、发布源码标识和签名资产身份。本次只发布测试包，现有服务器预览保持不变，不安装或重启。
- beta/prerelease，正式通道不变。配置和房间格式不迁移；后续如安装本包，需要重启 Emby Server。管理员页面仍延后至当前测试线转正式版之后。
