# Watch Together v1.6.0.5

## 新增与改进

- 插件管理页新增 GitHub Token 配置入口，管理员可设置、替换或清除用于测试版更新查询的 Token。
- 已配置 Token 时，beta 更新任务会用它认证 GitHub Releases API 查询，减少匿名 API 限额带来的失败；未配置时仍可匿名查询。
- 管理页调整了更新设置与 Token 配置的分组、输入宽度、按钮和帮助说明，加入获取 Token 的 GitHub 链接。

## 配置与兼容性

- Token 保存在独立凭据文件中，不写入通用插件配置、房间数据或页面回显。Linux 上凭据目录和文件分别使用 `0700`、`0600` 权限。
- Token 仅用于 beta Releases API 请求；stable 更新和两种通道的 DLL、manifest、signature 固定资产下载均不携带 Token。
- 此配置可选。未配置 Token 时 beta 继续使用匿名 API；已有 stable/beta 通道与签名验证行为保持兼容。

## 升级注意

- 请使用 Emby 管理员账号打开 Watch Together 页面，在“设置”中配置可选 Token；保存后页面只显示已配置状态，不会再次显示 Token 内容。
- 选择 beta 后，Emby 的“Watch Together 更新检查”计划任务会读取该 Token；Token 无效或存储异常时，检查会安全失败并显示可操作的提示。
- 本版本为 beta/prerelease。更改 Token 后可手动运行 Emby 更新检查任务验证连接；签名、哈希和程序集身份校验仍在安装前执行。
