# Watch Together v1.7.3.4 测试版

## 本次更新

- 「我的房间」和「后台管理」移除手动刷新按钮。前台通常每秒检查一次，页面隐藏时暂停，返回后立即检查。遇到读取失败时保留已显示的房间并自动重试。
- 接受邀请时，邀请码留空会弹出 Emby 提示。宿主无法显示提示时，输入框旁仍会显示错误。
- 后台房间卡片沿用「我的房间」的圆角外框和内缩媒体区。播放中显示影片封面，等待播放时显示原有插画，配色跟随 Emby 主题。

## 安装与验证

继续使用原有配置和房间数据。页面和控制器缓存键更新为 V35，更新插件并重启 Emby 后，请从插件菜单重新进入。

自动回归覆盖轮询、邀请提示及后台卡片。NAS 已核对同功能预览的插件加载和 V35 页面资源。真实客户端的双端播放与高并发负载仍待独立实测。
