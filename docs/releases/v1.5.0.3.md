# Watch Together v1.5.0.3

## 版本性质

- 本版本从 `beta` 分支发布为 GitHub prerelease，基于稳定版 `v1.5.0.0`。
- 本版本用于验证更新通道、同步状态安全、会话选择、消息发送和邀请清理修复。

## 修复内容

- beta 更新通道会在非 draft 的 stable 与 prerelease 中选择版本号最高且验证通过的版本；stable 通道仍只读取正式版。
- 手动暂停或继续发送失败时返回错误并记录诊断，不再留下阻塞后续自动同步的运行时错误。
- 管理员重新同步在 Barrier 或 Pending 命令存在时拒绝并保留现场；冲突或服务器不可用时不再发送“已发起重新同步”的通知。
- 初始会话绑定优先选择原始远控标志满足资格要求的会话，同时保留已进入 Watching 状态后的短时能力恢复。
- 多个共同 Item 全局同分时，仅在当前候选中存在唯一、完整且有效的历史 SessionId 与 ItemId 绑定组合时恢复选择。
- 房间消息和通知使用有界发送，并在退出房间 gate 后执行网络调用，发送失败不改变房间运行状态。
- 邀请成功创建房间后，同一创建者的其他待接受邀请一并失效；创建房间失败时保留邀请。

## 配置与兼容性

- 不新增配置项，不改变公开 REST API、房间持久化格式或发布签名信任链。
- 现有插件配置和房间数据可以继续使用。
- 后续正式版必须递增 MAJOR、MINOR 或 PATCH，例如 `1.5.1.0`，不得把 `1.5.0.x` 作为新的 stable 版本。

## 测试状态

- 完整 .NET 测试、Release 构建、路径防护、CI、签名和发布工作流静态检查已通过。
- 真实 Emby 双客户端、更新安装、慢客户端超时和邀请页面行为仍需在 beta 发布后验证。
