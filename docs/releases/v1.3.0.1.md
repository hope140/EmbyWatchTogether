# Watch Together v1.3.0.1

## 修复与改进

- 修复 Emby Theater 及嵌入式客户端在深色主题下管理页房间卡片显示为白色的问题。
- 调整深色主题下文字、placeholder 和 hover 状态的对比度，提升可读性。
- 兼容完整色变量和 HSL 分量变量，同时保留网页浅色主题的正常显示。

## 配置与兼容性

- 本次更新不改变同步逻辑、插件配置或 API，现有房间和配置可继续使用。
- 真实小秘客户端仍需在部署后进行实际界面验收；本说明不将静态兼容性检查视为客户端验收结果。

## 升级注意

- 更新插件后请重启 Emby Server，使新版本加载生效。
