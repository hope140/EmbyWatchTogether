# Watch Together v1.7.2.18 测试版

更新插件图像，修复普通账号打开页面时的用户列表误报。

## 本次变化

- 插件卡片使用已确认的 640×360 PNG，侧栏使用宿主 people 双人图标。
- 页面读取当前用户的明确角色，普通用户不再请求管理员专用用户列表，保留自己的房间与邀请；管理员保留原功能。角色读取失败仍显示错误，不授予管理权限，不隐藏真实服务器故障。
- 三个页面、共享控制器及路由引用统一升级为 V21，避免继续复用旧资源身份。
- 不修改同步、播放、服务端权限、SDK 离线回退、页面布局或更新安装逻辑。

## 验证与边界

- 用户已确认网页普通账号正常，并确认 V21 预览解决新版 Windows 客户端普通账号问题。自动测试覆盖角色失败、身份不匹配、账号/服务器/离页迟到结果、管理员 500 与资源键升级。
- 未在真实客户端人工注入全部异常，也不声称所有客户端视觉、交互或双端播放全量验收。
- 本包功能与已验收 1.7.2.17+role-preview2.20261112 对应；发布包具有 1.7.2.18 程序集版本、发布源码标识及签名身份。本次只发布，服务器继续运行原预览，不安装或重启。
- beta/prerelease，正式通道不变；不迁移配置或房间格式。后续安装需要重启 Emby Server。管理员页面仍延后至当前测试线转正式版之后。
