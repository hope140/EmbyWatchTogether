# Watch Together v1.8.0.0 正式版

## 本次更新

- 支持简体中文、繁体中文和英文界面。播放通知按账号使用最近一次打开插件页时保存的语言，中文 Emby 服务器上的用户菜单可显示为「同映」。
- 「我的房间」仅显示自己参与的房间。管理员可从「后台管理」查看所有房间、双方播放状态及主用户进度，并在确认后结束同步。
- 「我的房间」和「后台管理」在前台约每秒自动更新。页面隐藏时会暂停轮询，重新显示时继续。
- 创建邀请码后可查看有效期、手动复制，也可撤销有效邀请。接受邀请时，留空会显示 Emby 提示。
- 进度跳转超时后，如果两端已重新对齐并确认恢复同步，房间页会清除旧的「播放控制未完成」提示。此前的失败仍保留在诊断记录中。

## 安装与兼容性

升级前备份旧插件 DLL，然后按[安装说明（中文）](https://github.com/hope140/EmbyWatchTogether/blob/v1.8.0.0/README.md#%E5%AE%89%E8%A3%85) / [Install (English)](https://github.com/hope140/EmbyWatchTogether/blob/v1.8.0.0/README.en.md#install)替换 DLL 并重启 Emby Server。现有配置和房间数据可继续使用。重启后从 Emby 用户菜单重新进入插件。

自动回归覆盖语言选择、管理员与普通用户权限、同步及恢复状态。不同播放器在真实播放中的行为见[客户端兼容性记录](https://github.com/hope140/EmbyWatchTogether/blob/v1.8.0.0/docs/client-compatibility.md)。
