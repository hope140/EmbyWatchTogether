# Watch Together v1.4.4.0

## 修复与改进

- 将 `1.4.3.1` 与 `1.4.3.2` 测试版验证的兼容性修复纳入正式通道。
- 已完成起播同步且保持同一会话、同一视频时，一端远控标志短暂丢失最多等待 8 秒恢复，避免另一端被不必要地暂停；恢复窗口内不发送新的同步命令。
- 更新检查结果通过 Emby 管理端短提示反馈，覆盖已是最新、发现版本、安装成功、等待重启以及失败等状态。
- 房间接口继续使用稳定错误码，未初始化时返回可重试状态；房间响应仅保留当前参与者的受限摘要，避免暴露完整用户目录或用户 GUID。
- 增加远程控制能力诊断，便于定位设备的同步资格问题。

## 配置与兼容性

- 现有房间、配置格式、更新通道和初始同步资格保持兼容，无需迁移数据。
- 8 秒恢复窗口只适用于处于 `Watching` 且会话身份连续的播放；换片、停止、离线、长期断线和其他条件变化仍按原有安全规则进入等待和重新同步。
- stable 用户可通过正式更新通道获取本版本；管理员仍可在配置页选择 beta 通道以接收后续测试版。

## 升级注意

- 更新安装完成后需要重启 Emby 才能加载新版本。
- 如遇不同步，请保留 Emby 服务器日志和两端客户端日志，并记录两台设备的时钟差，便于排查。
