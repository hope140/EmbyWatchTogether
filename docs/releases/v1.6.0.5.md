# Watch Together v1.6.0.5 候选说明

## 新增与改进

- 管理员可在插件管理页保存或清除自己的 GitHub Token，并查看是否已配置；页面不会回显 Token。
- 选择 beta 更新通道时，Token 只用于查询 GitHub Releases API。未配置 Token 时继续匿名查询。
- stable 通道保持原有固定下载地址；DLL、manifest 和 signature 下载均不携带 Token。

## 配置与安全

- Token 保存在独立凭据文件中，不进入通用插件配置或房间数据。Linux 上凭据目录和文件分别使用 `0700`、`0600` 权限。
- Token 无效或存储异常时，更新检查会给出可操作的错误提示，不会在存储异常后退回匿名请求。签名、哈希和程序集身份校验保持不变。

## 验收状态

- 这是用于 NAS 管理页和更新检查验收的本地候选构建；本文不表示已经创建 GitHub Release。
- 真实 Token 认证、Emby 管理页显示和 NAS 更新任务结果仍需部署后验证。
