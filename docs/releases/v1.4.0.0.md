# Watch Together v1.4.0.0（正式版）

## 本次变化

- 增加更新通道选择，管理员可以在插件配置页选择正式版 `stable` 或测试版 `beta`。
- `stable` 默认启用，继续使用正式 Release 的 `releases/latest` 入口。
- 选择 `beta` 后，更新任务会从 GitHub Releases API 选择最新的非 draft prerelease，并按固定 tag 资产检查更新。
- stable 和 beta 都复用发布清单、RSA 签名、程序集版本、文件大小和 MD5 校验；校验失败时不会安装。

## 配置与兼容性

- 老配置没有 `UpdateChannel` 字段时按 `stable` 处理；未知值也安全回落到 `stable`。
- 更新通道只影响更新任务获取的发布线，不改变房间、同步、REST API 或已有播放设置。
- beta 是预发布版。选择 beta 后，Emby 的“Watch Together 更新检查”计划任务会按所选通道检查并自动安装；任务的启用状态和执行计划仍由 Emby 管理。

## 升级注意

- 安装后需要重启 Emby 才会加载新版本。
- 如果只想使用正式版，保持更新通道为 `stable`；如需测试 beta，请在插件配置页选择 `beta` 后手动运行一次更新检查任务。
- 自动化测试和静态验签不等于真实客户端验收；遇到异常时可按 README 的回滚说明恢复旧 DLL。
