# Watch Together v1.7.2.2 测试候选

- 保留 1.7.2.1 的 Pause → Seek → Restore 加速和有界提示队列。
- Waiting Pause 达到重试限额后，仅双方完整同步资格恢复才清除整组旧状态。同视频不再被当作远控恢复依据。
- Waiting 中仅一端 Session 或 Item 变化时，按目标清理陈旧命令，保留未变化对端的耗尽预算。能力变化保留原有按目标恢复方式。
- 显式用户重新同步仍允许开启新周期；Seek ±2 秒、Unpause 布尔确认及 manual_action 判定保持原行为。

验证记录：9 条定向回归、620 条完整 .NET 测试通过，Release 构建零警告零错误。原同视频循环在夹具中发送 58 次 Pause，超过总计 6 次限额；陈旧 Session/Item 的已接受但未确认命令也有去掉修复即失败的回归。独立源码审查未发现本范围剩余阻断项。

本版本仅供 NAS 实机测试，不发布公开 Release。CI、准确提交和部署 DLL 哈希另行记录；双客户端实机验收待用户明晚执行。通信异常初因仍未知。
