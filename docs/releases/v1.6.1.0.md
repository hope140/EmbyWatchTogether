# Watch Together v1.6.1.0

## 新增与改进

- 改进主用户停止观察和晚到换集处理，主用户较晚打开新 Item 时可继续走换集衔接流程。
- 支持手动或自然换集后的播放衔接；参与者会在满足远程控制条件时打开主用户当前 Item，再完成同步对齐。
- 非主参与者短暂丢失播放会话时，保留原 User、Session 和 Item 的短时恢复机会，恢复后重新完成同步对齐。
- 对正常观看中的小幅漂移采用保守、低频的修复策略，并提供脱敏诊断信息帮助定位同步问题。
- 管理页面继续使用 Emby 原生单页区域和控件样式，内容宽度、按钮文字对齐及主操作主题色保持一致。
- 更新检查改进版本选择和固定资产下载的容错；可选 GitHub Token 仅用于 beta Releases API 认证，页面不会回显 Token。

## 配置与兼容性

- 房间、插件配置和已有持久化数据保持兼容，无需迁移。
- 重启后未接受的邀请会被丢弃；已保存的房间和配置仍按原有规则保留。
- GitHub Token 为可选设置；未配置时 beta 更新检查继续使用匿名 API，stable 更新和固定资产下载保持原有路径。

## 升级注意

- 安装插件后需要按 Emby 提示重启服务器，使新版本生效。
- 手动或自然换集依赖客户端支持远程控制；不同客户端、网络条件和媒体场景仍应按实际使用情况观察。
- 本版本的同步诊断和自动恢复用于安全等待与问题定位，偶发的被控方多跳集问题仍需继续收集现场证据。
