# Watch Together v1.3.0.4（Beta）

## 本次观察内容

- Session snapshot provider 连续失败达到 2 秒后才进入 `Waiting` 保护，清理不可信同步状态且不向旧 session 发命令；恢复需连续成功 2 秒后使用 fresh snapshot 重新同步。弱网抖动不会频繁触发 Barrier。
- 管理页遇到 `snapshot_unavailable` 时提示快照不可用，不声称播放器已暂停。
- 多个共同 Item 候选使用对称 maximin 全局评分选出唯一共同 Item；完全同分时安全等待。
- 不修改 API、配置格式或既有阈值。
