# Watch Together v1.4.1.0

## 新增与改进

- “Watch Together 更新检查”计划任务检查后如果当前已经是最新版本，会向当前在线的管理员会话发送一条短提示，显示当前版本和更新通道。
- 发现新版本并成功安装时，仍按原流程通知 Emby 等待重启；无更新提示发送失败不会影响检查任务本身的结果。

## 配置与兼容性

- 不新增配置项，不改变 stable/beta 更新通道选择、签名校验或自动安装条件。
- 提示仅发送给检查时在线的管理员会话；没有在线管理员会话时仍会写入更新检查日志。

## 升级注意

- 安装后需要重启 Emby 才会加载新版本。
- 自动化测试不等同于真实客户端验证；遇到异常时可按 README 的回滚说明恢复旧 DLL。
