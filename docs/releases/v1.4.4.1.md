# Watch Together v1.4.4.1

## 版本性质

- 本版本从 `beta` 分支发布为 GitHub prerelease，兼容基线为正式版 `v1.4.4.0`。
- 本包包含 S1—S3 的回归保障、房间诊断和诊断页面能力，用于继续进行 beta 验证。
- S4 参与者自主重新同步以及真实双端播放验收不包含在本版本中。

## 新增与改进

- 增加 PR 和 beta 分支的自动构建、测试与产物检查。
- 增加只读房间诊断接口，提供状态原因、快照健康、会话能力、Pending、Barrier、恢复窗口、最近结果和有界事件记录。
- 增加诊断页面展示和脱敏 JSON 导出；页面入口与控制器使用新的缓存键，避免 Emby Web 继续使用旧页面缓存。
- 诊断导出采用字段白名单和稳定别名，不包含真实用户名、用户或会话 GUID、Token、路径或底层异常文本。

## 配置与兼容性

- 现有房间、同步状态机、配置格式和管理员控制路径保持兼容，无需迁移数据。
- 诊断中的位置、能力和确认延迟是服务端观察值，不等同于播放器已经执行或双端已经对齐。
- 插件默认使用 `stable` 通道；管理员选择 `beta` 后，Emby 更新任务才会获取本测试版。

## 升级与测试注意

- 安装完成后需要重启 Emby 才能加载新版本。
- 当前已在 Emby Web `4.9.5.0` 管理员登录态下验证诊断展示和 JSON 导出；同步中的 Barrier、Pending 控制、非管理员入口和真实双端播放仍待后续实机验收。
- 如需回退，使用 Emby 插件管理或保留的上一版签名资产，不要手工修改已发布 tag。
