# Watch Together v1.7.2.1 测试候选

## 修复与改进

- 保留 [1.7.2.0](v1.7.2.0.md) 的六项逻辑修复，继续保护命令超时、停止后的暂停、换片控制冲突、状态读取和更新状态。
- 起播对齐在当前条件已满足时继续推进下一阶段，减少轮询等待；已满足的暂停与恢复状态不重复发送命令，实际发送后仍等待后续快照确认。
- 手动拖动进度后，在检测当轮开始暂停对齐，继续使用固定目标与原播放意图。
- 同步提示通过有界队列发送，慢提示不占用播放控制的会话槽；过期或目标身份变化的排队提示被丢弃。

## 配置与验收

- 房间与插件配置格式保持兼容，无需迁移。
- 先完成本地回归和构建，再核对候选 DLL 身份及服务器加载；这些检查与真实双客户端验收分别记录。
- 实机重点覆盖双方起播、暂停/继续、拖动进度、主用户换集，以及继续后立即停止时另一端的暂停。
- 本候选用于本轮实机测试，公开测试版发布在用户验收后另行执行。
