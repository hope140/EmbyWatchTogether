# Watch Together v1.4.5.2

## 版本性质

- 本版本从 `beta` 分支发布为 GitHub prerelease，兼容基线为 `v1.4.5.1`。
- 本版本是阶段 C 的修订版，重点收口房间关系和邀请码失败反馈。

## 修订内容

- 已属于房间的用户创建邀请码时返回稳定状态，并显示“请先结束当前房间”的明确提示。
- 邀请数量达到上限时不再显示“服务器暂时不可用”。
- 管理员创建和自助创建的房间，任一参与者都可以结束房间并解除成员关系。
- “退出房间”改为“暂离房间”，明确暂离只退出同步状态，不解除成员关系。
- 页面去掉流程编号，统一“暂离”“结束房间”和成员关系文案。

## 保持的边界

- 一名用户仍不能同时属于多个房间。
- `Leave` 不会删除成员关系；只有结束房间才会解除关系。
- 邀请、房间和同步状态仍只支持同一服务器的双人观看。

## 测试状态

- 自动测试、Release 构建、发布静态检查和 Windows CI 已通过。
- 部署后需要继续完成真实双账号邀请链路，再决定是否推进 `1.5.0.0` stable。
