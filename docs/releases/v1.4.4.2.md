# Watch Together v1.4.4.2

## 版本性质

- 本版本从 `beta` 分支发布为 GitHub prerelease，兼容基线为正式版 `v1.4.4.0`。
- 本包包含 S1—S4 的回归保障、房间诊断、诊断页面和参与者重新同步能力。
- 这是测试版，不代表真实双端播放已经完成验收。

## 新增与改进

- 已加入房间的普通参与者可以请求重新同步。
- 服务端在房间 gate 内复核成员、加入状态、服务器身份、快照保护、Barrier 和 Pending 状态。
- 请求成功后复用现有 `Waiting → Barrier` 流程；同步进行中或重复请求会返回稳定的 busy 原因。
- 页面仅向已加入的非管理员显示“请求重新同步”，并反馈 accepted、busy 和 unavailable 状态。
- 管理员原有暂停、继续和重新同步控制路径保持兼容。

## 配置与兼容性

- 现有房间、同步状态机、配置格式和管理员控制路径保持兼容，无需迁移数据。
- 参与者重新同步只复位内存中的房间 runtime，由现有轮询重新建立 Barrier，不直接覆盖正在确认的命令。
- 插件默认使用 `stable` 通道；管理员选择 `beta` 后，Emby 更新任务才会获取本测试版。

## 升级与测试注意

- 安装完成后需要重启 Emby 才能加载新版本。
- 自动测试和构建已通过；参与者重新同步的双客户端播放、Barrier 和 Pending 实机验收仍需在测试环境完成。
- 如需回退，使用 Emby 插件管理或保留的上一版签名资产，不要手工修改已发布 tag。
