# 后台管理卡片预览

普通房间页始终只显示本人参与的房间。后台管理和建房时的全站成员冲突检查使用管理员授权的 `Scope=all`。后台额外请求 `IncludePlayback=true`，服务端复用同步轮询已选中的双端会话，按房间读取一致的运行状态。此摘要只用于显示。

两端须在同一有效同步条目上并有可靠播放样本。进度取主用户，缺失位置时省略，失活、切集、停止或样本过期时清除旧媒体。仅在卡片进入视口后，通过当前用户的 Emby 媒体 API 获取标题及同源横图；相同条目在当前页面共用短期缓存。没有同步影片时复用“我的房间”的等待插画；有同步影片但缺少封面时显示片名和主题底色。结束同步使用原有结束房间接口并确认双方，不向播放器发送停止命令。

用户确认接受本次预览用于测试版发布。NAS 曾运行 1.7.3.2 内部构建，核对插件启动与 V33 页面资源。截图和自动回归来自模拟宿主，真实客户端的双端播放、全量权限、剪贴板及高负载仍待独立验证。公开测试版变化见[v1.7.3.3 发布说明](../releases/v1.7.3.3.md)。
