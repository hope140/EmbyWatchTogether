# Watch Together v1.8.0.4 测试版

## 本次更新

- 新增西班牙语和巴西葡萄牙语，覆盖房间、邀请、管理及设置页面。
- 播放通知使用各账号最近打开插件页面时的语言。使用西语或葡语建房时，未填写名称的房间显示为「Sala #1234」这类名称；已有房间名不变。

## 安装

首次安装推荐 [v1.8.0.0 正式版](https://github.com/hope140/EmbyWatchTogether/releases/tag/v1.8.0.0)。从 v1.8.0.3 升级可保留配置和房间数据。替换 DLL 后重启 Emby Server，再重新打开插件页面。
