# Watch Together v1.6.1.0

## 新增与改进

- 改进等待阶段的暂停确认、主用户停止观察和晚到换集处理，减少会话短暂变化时的误判。
- 支持手动或自然换集后的播放衔接；参与者会在满足远程控制条件时打开主用户当前视频，再完成同步对齐。
- 另一位参与者短暂丢失播放会话时，为原会话和原视频保留短时恢复机会，恢复后重新完成同步对齐。
- 持续明显的播放偏移可触发保守、低频的重新对齐，并提供脱敏诊断信息帮助定位同步问题。
- 管理页面保留原有单页区域，按钮、输入框等采用 Emby 原生控件样式；统一内容宽度，居中按钮文字，并以原生描边区分普通操作。
- 更新检查改进版本选择和固定资产下载的容错；可选 GitHub Token 仅用于 beta Releases API 认证，页面不会回显 Token。

## 配置与兼容性

- 房间、插件配置和已有持久化数据保持兼容，无需迁移。
- 重启后未接受的邀请会被丢弃；已保存的房间和配置仍按原有规则保留。
- GitHub Token 为可选设置；未配置时 beta 更新检查继续使用匿名 API，stable 更新和固定资产下载保持原有路径。

## 升级注意

- 安装插件后需要按 Emby 提示重启服务器，使新版本生效。
- 手动或自然换集依赖客户端支持远程控制；不同客户端、网络条件和媒体场景仍应按实际使用情况观察。
- 新增的换集与恢复诊断便于收集现场证据；偶发的被控方多跳集问题仍需结合实际客户端排查。
