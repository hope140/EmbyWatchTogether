# Watch Together v1.7.3.3 测试版

## 变化

- 普通房间页只显示当前账号参与的房间，管理员账号也遵循此范围。
- 新增管理员专用的「后台管理」，集中展示所有房间、双方与主用户。服务端独立验证管理员权限。
- 卡片展示已确认的同步影片、播放或暂停状态、主用户进度及百分比。没有同步影片时显示房间页的双座影院插画。有影片但缺封面时显示片名和主题底色。
- 管理员可在卡片上确认结束同步。结束同步解除房间关系，双方设备可继续各自播放。
- 邀请页在没有有效邀请时隐藏底部列表，读取失败单独提示。创建后可查看邀请码及到期时间、手动复制或撤销。创建、复制、接受和撤销成功时使用 Emby 提示，复制失败时可选中邀请码手动复制。
- 支持简体中文、繁体中文和英文。页面和控制器缓存键更新为 V33，请从插件菜单重新进入。

## 验证

用户已接受此预览用于测试版发布。自动回归覆盖管理员权限、卡片状态切换、邀请创建与撤销、复制及接受。NAS 已核验预览插件加载、服务恢复和 V33 资源。真实客户端的双端播放与剪贴板操作仍待独立实测。

本测试版沿用现有配置和房间数据结构。
