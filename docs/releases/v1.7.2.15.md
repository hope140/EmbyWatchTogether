# Watch Together v1.7.2.15 测试版

整理页面文案和标题层级，让房间列表刷新结果更清楚。

## 本次变化

- 精简房间、创建与设置页面的重复说明，保留缺项和错误反馈、操作副作用、管理员权限、自动安装及重启生效说明。
- 设置开关逐行排列，统一说明间距，收起空提示占位；“房间”标题与创建、设置页面同级，窄屏同步缩放，刷新按钮居中对齐。
- 成功刷新不再显示“已更新 N 个房间”。失败提示位于房间标题与列表之间，正常时不占空间；首次加载失败提示重试，保留旧列表时说明列表可能不是最新。
- 自动轮询不重复播报相同错误，恢复只清除列表自身提示；手动刷新保留其他操作失败、部分成功和创建成功反馈。旧列表仅供展示，不能恢复过期数据的表单或确认校验资格。

## 验证与边界

- 覆盖首次失败、旧列表失败、恢复、手动重试、轮询、生命周期和消息隔离，以及 320/390/1440px 浅深色标题一致性与按钮对齐。
- 用户已确认四轮页面预览可进入测试发布；自动化和模拟宿主截图不代表真实客户端全量交互或双端播放验收，继续通过日常使用收集反馈。
- 本次不修改同步引擎、播放协议或管理员页面。管理员页面安排在当前测试线转正式版之后，另行确认范围。
- beta/prerelease，正式通道不变；配置和房间格式不迁移。安装后需要重启 Emby Server。发布资产与此前 1.7.2.14 本地预览 DLL 不同，以签名、版本和哈希核对安装身份。
