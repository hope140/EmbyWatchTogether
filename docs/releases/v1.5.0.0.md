# Watch Together v1.5.0.0

## 版本性质

- 本版本从 `main` 分支发布为 GitHub stable Release，兼容基线为 `v1.4.5.0`。
- 本版本将 `v1.4.5.1` 与 `v1.4.5.2` beta 中的阶段 C 自助邀请和房间生命周期能力纳入正式通道。

## 新增与改进

- 普通用户可以创建 15 分钟有效的一次性邀请码，邀请码只保存校验值，不写入 `rooms.json`。
- 另一位已认证用户接受邀请码后，服务端原子创建双人自助房间并消费邀请码。
- 支持有效邀请查询、撤销、过期、重放保护、并发接受保护和接受尝试速率限制。
- 自助房间的创建者和参与者可以结束自己的房间，结束后解除成员关系；“暂离房间”只退出同步状态。
- 邀请失败、房间占用和成员关系提示使用稳定的用户可读反馈，管理员旧式建房和同步控制保持兼容。

## 配置与兼容性

- 现有 `rooms.json` 可继续读取；旧房间缺少新增字段时按管理员创建的旧式房间处理。
- Emby 重启后未接受的邀请码失效，需要重新创建；已经创建的房间不受影响。
- 插件默认使用 `stable` 通道；管理员仍可选择 `beta` 获取后续预发布版本。
- 邀请、房间和同步状态仍只支持同一服务器的双人观看，不引入多人、跨服务器或任意换片。

## 升级注意

- 安装完成后需要重启 Emby 才能加载新版本。
- 稳定版更新仍通过 `releases/latest` 获取签名资产；回退时使用上一版签名资产或 Emby 插件管理中的备份，不手工修改已发布 tag。
- 不同客户端和长时间播放仍建议持续观察，实际播放行为取决于 Emby 客户端提供的会话和远程控制能力。
