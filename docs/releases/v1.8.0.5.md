# Watch Together v1.8.0.5 测试版

## 本次更新

- 多个房间可同时推进同步，单个房间等待播放器响应时，其他房间可继续对齐。每条播放命令从实际发送时开始计时，避免刚发出就被判定超时重试。
- 暂离时先尝试暂停留在房间的一方，再发送提示。提示发送失败时，页面仍会显示实际的暂停结果。
- 同一个账号有两台播放器评分相同时，房间状态和管理员播放控制会沿用仍有效的绑定设备。没有可确认的绑定时，会跳过有歧义的那一端。
- 结束房间后会补读最新列表。已有列表请求还在返回时，结束按钮保持禁用，直到新列表更新房卡。
- 切到新一集时，页面立即读取新片名和背景。上一集的结果即使迟到，也不会覆盖当前显示。

## 安装与验收

从 v1.8.0.4 升级可保留配置和房间数据。替换 DLL、重启 Emby Server 后，请从 Emby 菜单重新打开「一起观看」。

双端测试可以先在同步中点暂离，确认留下的一端暂停。重新加入并恢复同步后，由主用户换集，确认对方跟随且房间卡更新到新一集。最后结束房间，确认房卡消失，之后两端可以各自播放。本版本的真实客户端验收仍在进行。
