# Watch Together v1.7.2.10 测试版

本版修复 1.7.2.9 中主控停止旧集、稍后开始新集时，被控可能停留在旧集而没有收到换集指令的问题。

## 修复与兼容

- 将停止前观察到的播放历史与当前可接收命令的播放代次分开，恢复原有候选窗口内的迟到换集跟随。
- 保留旧快照撤销和发送前校验；明确的新 Start 才能作为停止后换集的依据，迟到 Progress 不会重新激活旧播放。
- 被控停止后即使复用同一播放 ID 重开，也不会继承原换集候选；身份变化和候选过期仍停止自动跟随。
- 保持原有 2 秒停止确认和最多 10 秒换集候选窗口，不增加等待下一条进度的普通快进延迟。
- 沿用现有配置和房间格式，无需迁移；不修改 ETE 或客户端协议。

## 验证与边界

- 新增真实 SessionBridge、SDK SessionInfo、SyncEngine 和命令发送器串联的离线回归，核验模拟 Emby 发送边界上恰好一次换集指令。
- 覆盖服务端状态替换、2.635 秒及 3.3 秒延迟、快速切集、同/新播放 ID、无明确 Start、过期、被控停止或身份变化，以及普通暂停、恢复和定位。
- 保留旧快照与排队命令防护回归；离线自动化验证不等同于 NAS 和真实双客户端播放验收。
- Stop 前未观察到有效播放身份、同对象复用 ID 且事件乱序等既有协议边界仍存在；本版不声称解决首次 EOF 或所有播放失败。

本版为 beta/prerelease，正式通道保持原版本。安装需要重启 Emby Server，应在确认没有进行中的播放后操作。
