# Watch Together v1.4.5.0

## 版本性质

- 本版本从 `main` 分支发布为 GitHub stable Release，兼容基线为 `v1.4.4.0`。
- 本版本纳入 S1—S4 的回归保障、房间诊断、诊断页面和参与者重新同步能力。
- beta 阶段的非管理员入口和 S4 实机验收已完成。

## 新增与改进

- 增加 PR 和 beta 分支的自动构建、测试与产物检查。
- 增加只读房间诊断接口、脱敏页面展示和 JSON 导出。
- 非管理员可从 Emby 用户菜单进入 Watch Together 页面，只看到自己参与的房间。
- 已加入房间的参与者可以请求重新同步；服务端会在房间 gate 内检查成员、服务器、Barrier、Pending 和快照保护状态。
- 诊断事件服务端保留最近 500 条，页面和导出显示最近 50 条，最新事件排在前面。
- 诊断详情会在房间状态轮询后保持展开和可见。

## 配置与兼容性

- 现有房间、同步状态机、配置格式和管理员控制路径保持兼容，无需迁移数据。
- 参与者重新同步复用现有 `Waiting → Barrier` 流程，不直接覆盖正在确认的命令。
- 插件默认使用 `stable` 通道；管理员仍可选择 `beta` 获取后续预发布版本。

## 升级与测试注意

- 安装完成后需要重启 Emby 才能加载新版本。
- 当前版本已通过自动测试、签名发布和测试环境实机验收；不同客户端和长时间播放仍建议持续观察。
- 如需回退，使用 Emby 插件管理或保留的上一版签名资产，不要手工修改已发布 tag。
