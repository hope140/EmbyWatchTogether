# Watch Together v1.7.2.16 测试版

整理成功通知与创建表单，并准确区分配置保存各阶段的结果。

## 本次变化

- 配置读取成功不再显示重复小字；保存成功使用 Emby toast“配置已保存”，忙碌时仅保留按钮“保存中…”与禁用状态。
- 创建成功提示“房间已创建”并重置表单；空表单初始不报缺项，编辑后就近提示，点击创建时定位缺项。忙碌、权限、用户数据和成员冲突校验继续保留；暂离不会解除成员关系。
- 房间结束成功提示“房间已结束”，确认前副作用说明不变。加入、成功暂离、邀请码复制/撤销和 Token 操作使用真实语义的成功 toast；错误、部分失败、邀请码及有效期、必要配置状态继续可见。
- 保留已有 toast 备用提示与生命周期保护；组件加载或显示失败不改变已完成的业务，也不自动重发请求。
- 配置保存仍按读取、提交、回读执行。保存前读取失败说明尚未提交；提交请求失败说明结果尚未确认；提交成功但回读失败提示“配置已提交，但暂时无法确认，请重新读取检查”。正常成功提示不变；没有新增自动重试或超时机制。

## 验证与边界

- 自动测试覆盖各阶段失败、提交后连接断开导致结果不确定、正常成功、busy 防重复、账号/服务器及页面生命周期失效、toast 模块失败与表单校验重置。
- 用户认可难以人工复现的保存异常由自动测试验证；没有在真实服务器注入保存故障，不宣称这些分支已人工验收。模拟宿主截图和模块契约核验也不等于真实客户端或屏幕阅读器全量验收。
- 本版页面资源与服务器预览 1.7.2.15+toast-preview3.20261112 一致；发布包具有新的程序集版本、源码标识和签名资产身份，不与本地预览 DLL 混同。本次只发布测试包，不安装或重启现有服务器；需要同步安装时另行确认。
- beta/prerelease，正式通道不变。配置和房间格式不迁移，安装后需要重启 Emby Server。未修改同步引擎、播放、权限或更新安装行为；管理员页面仍延后至当前测试线转正式版之后。
