# Watch Together v1.5.0.1

## 版本性质

- 本版本从 `beta` 分支发布为 GitHub prerelease，基于稳定版 `v1.5.0.0`。
- 本版本针对双方打开不同视频后的 Waiting 暂停循环进行修复验证。

## 修复内容

- 不同 Item 时，Waiting Pause Pending 按每位参与者自己的 SessionId 和 ItemId 确认，不再因另一端 Item 不同而被误清。
- 已确认暂停后再次播放的 Waiting Pause 发送改为按会话和能力条件有界处理，避免每轮无限重复暂停。
- 暂停尝试达到上限后保持明确等待状态；双方恢复到同一 Item 时可以重新进入 Barrier。

## 保持的边界

- 不跨 Item 执行 Seek，不把不同视频直接合并到同一同步序列。
- 正常 `Watching` 状态下的暂停、继续和手动拖动同步行为保持不变。
- 同一服务器双人房间和现有 Session/Item 身份绑定规则保持不变。

## 测试状态

- 完整 .NET 测试、Release 构建、路径防护、签名和发布工作流静态检查已通过。
- beta 部署后仍需继续观察真实 Emby 客户端的不同视频和重新打开同一视频场景。
