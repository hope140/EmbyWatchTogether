# Watch Together v1.4.2.0

正式版，基于 `main` 打包发布。

## 变更

- 修复计划任务检查后“当前已是最新”提示不可见的问题。
- 已是最新时改用 Emby Web 可识别的 `GeneralCommand / DisplayMessage` 通道，当前管理员会话会显示与更新成功相同的短横条提示。
- 保留 stable/beta 更新通道、签名校验和安装后等待重启流程不变。

## 兼容性与升级

- 版本从 `1.4.1.0` 升级到 `1.4.2.0`，前三段中的 PATCH 变化，属于正式版 stable。
- 不需要迁移配置；现有房间和更新通道设置保持不变。
- 更新安装后仍需重启 Emby 才会加载新插件。

## 验证边界

- 已完成更新管理器、计划任务和消息工厂自动化测试。
- 本次只发布 GitHub Release，不执行服务器部署；生产 Emby 上的实际浏览器显示需在安装后由计划任务或手动运行一次确认。
