2. 房间

状态变为“同步中”后，两位参与者会自动保持一致。

使用方法

  1. 创建房间并选择两名参与者。
  2. 两人分别登录 Emby，打开同一视频。
  3. 看到“同步中”后即可一起观看。

一方暂时不在线时，房间会等待；恢复后会继续尝试同步。
