# Watch Together v1.3.0.2

## 本次修正

- 修正小秘 Windows 客户端中的房间卡片颜色。该客户端的 `--theme-background-color` 是页面蓝色背景，房间卡片如果沿用页面背景变量，会在卡片区域显示成突兀的深蓝色，和网页端或客户端其他面板不一致。
- 房间卡片改用客户端提供的 `--card-background-*` 主题变量，并保留 `hsla()` 的透明度能力；默认 `alpha` 为 `1`，在未提供完整主题变量时仍显示为不透明卡片，避免回退为页面蓝底。
- 未修改房间同步、按钮操作、服务端 API 或数据格式；`v1.3.0.1` 的发布内容和历史 tag 保持不变。

## 升级与验证

1. 更新插件 DLL 后重启 Emby Server，使嵌入式管理页资源重新加载。
2. 在小秘 Windows 客户端重新打开 Watch Together 管理页；如仍看到旧颜色，退出并重新打开客户端，或清理该客户端的页面缓存后再检查。
3. 重点确认“房间”卡片与页面主题协调，卡片正文、状态徽章和按钮文字仍清晰可读；网页端浅色主题应继续显示浅色不透明卡片。

本版本只修正管理页的主题兼容性。发布校验会检查项目三项版本、程序集版本、manifest 版本和 tag 的一致性；客户端视觉复验仍需在实际小秘 Windows 客户端中完成，自动化测试不能替代该检查。
