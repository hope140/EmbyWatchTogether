# Watch Together v1.7.2.2 测试版

本版本仅更新 EWT 服务端插件，客户端无需修改。NAS 实机测试已由用户确认验收通过，本次通过 beta 通道发布。

## 修复与改进

- 为 Emby 远控调用增加有界等待与在途控制，避免阻塞房间轮询；保留停止后的暂停行为。
- 缩短 Pause → Seek → Restore 阶段之间的调度等待，并使用有界提示队列，减少提示发送对同步轮询的影响。
- Waiting Pause 达到重试限额后，仅在双方完整同步资格恢复时清除整组旧状态，避免将“仍是同一视频”误判为远控恢复。
- Waiting 中仅一端 Session 或 Item 变化时，按目标清理陈旧命令，保留未变化对端的耗尽预算；显式用户重新同步仍可开启新周期。
- 修复换集过程中的控制冲突和状态读取竞争，兼容历史版本标签，并保留安装后的待重启更新状态。

## 兼容性与升级

- 保持既有配置、客户端接口和同步协议；Seek ±2 秒、Unpause 布尔确认及手动操作判定沿用现有行为。
- 这是 beta/prerelease 测试版；使用 beta 更新通道或手动安装服务端插件后，重启 Emby 使新插件生效。
- 原通信异常的初因尚未确定，本版本针对已验证的问题和边界进行修复。

## 验证

候选源码已通过 9 条定向回归、620 条 .NET 测试及 Release 构建；对应 PR CI 的 Windows 插件测试、发布门禁和浏览器 UI 测试均通过。用户已确认 NAS 使用测试通过。签名发布资产由发布工作流另行构建、校验和生成。
