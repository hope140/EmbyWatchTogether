# Watch Together v1.7.2.5 测试版

本版本修复停止同步、发送提示和更新安装时的边界问题，并补充过期快照的中文诊断提示。

## 修复与改进

- 停止或释放同步引擎后，迟到的会话查询和控制结果不再继续推进同步或换集流程；同时避免取消回调与房间操作相互等待。
- 排队发送的同步提示在实际发送前重新核对当前状态。房间成员、客户端会话或播放项目已经变化时，跳过不再适用的提示。
- 更新安装后的管理员提示增加等待上限，避免慢客户端长期阻塞更新任务和任务取消。
- 诊断页面以中文显示“忽略过期快照”和“活动时间较旧”，便于识别被跳过的旧状态。
- 构建脚本拒绝覆盖源码等受保护目录，以及经过符号链接或目录联接的输出路径，避免错误的输出设置清理项目文件。
- 修正文档中的更新任务名称和页面缓存版本说明。

## 配置与兼容性

- 沿用现有房间和配置格式，无需迁移；更新通道默认值、签名验证和信任密钥保持不变。
- 房间仍为同一台 Emby Server 上的两名用户；双方需使用支持远控的客户端和 1 倍速播放。

## 升级注意

- 本版用于 beta/prerelease 通道；Latest 正式版保持 v1.7.1.0。
- 安装后按提示重启 Emby Server。网页可完整刷新后重新进入一起看，桌面客户端可完全退出后重新打开。
- 本轮验证覆盖自动化测试和构建；真实服务器升级、双客户端播放与长时间运行仍需实际使用反馈。
