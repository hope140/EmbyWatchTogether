2. 房间

状态变为“同步中”后，两位参与者会自动保持一致。

使用方法

  1. 创建房间并选择两名参与者。
  2. 两人分别登录 Emby，打开同一视频。
  3. 看到“同步中”后即可一起观看。

一方暂时不在线时，房间会等待；恢复后会继续尝试同步。

设置

播放停止行为与插件信息。

播放停止行为

停止或退出视频时，选择是否暂停另一方播放，以及是否向另一方发送文字提示。

覆盖暂停、继续、进度调整、重新同步、加入、退出、视频不一致和同步完成提示；播放端提示约 3 秒自动消失。
此设置由 Emby 服务器保存，仅管理员可以修改。
